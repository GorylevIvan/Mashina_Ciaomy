# Mashina_Ciaomy
Допустим, у нас есть две камеры, каждая из которых снимает одну и ту же сцену.
Мы делаем прогноз на основе этой сцены (например, определяем позу человека).
Для повышения надежности алгоритма обнаружения мы усредняем прогнозы, полученные с обеих камер в каждый момент времени.
Данные камеры представляют собой пару (кадр, временная метка), где временная метка представляет момент, когда кадр был снят камерой.

Задача:
Для каждого кадра camera1 нам нужно найти индекс соответствующего кадра, полученного camera2.
Кадр i из camera2 соответствует кадру j из camera1, если abs(временные метки[i] - timestamps[j]) минимально для всех i.
